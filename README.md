# Business Intelligence & Performance Visualizations Portfolio

A Python-based data analytics suite engineered to parse real-world operational datasets and compile clean, publication-ready visual plots. This portfolio handles data mapping across web traffic diagnostics, inventory performance indexes, and multi-channel revenue flows.

## 📊 Individual Projects Reference

### 🌐 1. Web Traffic Metrics & Acquisition Channel Analytics
* **Source Scripts:** `p1.py`, `p2.py`, `p3.py`
* **Target Datasets:** `website.csv`
* **Rendered Outputs:** Daily visitor line plots, marker indicators, and dynamic channel trends (Organic vs. Social vs. Ad tracking over weekly intervals).

### 📦 2. Product Volume Distribution Profiles
* **Source Scripts:** `p4.py`, `p5.py`, `p6.py`
* **Target Datasets:** `IT products.csv`
* **Rendered Outputs:** Vertical product comparisons, value labels, and horizontal rank metrics tracking consumer hardware flows (laptops, printers, peripherals).

### 🛍️ 3. Comparative Retail Channels Analysis
* **Source Scripts:** `p7.py`
* **Target Datasets:** `sales.csv`
* **Rendered Outputs:** Dual grouped bar graphs plotting side-by-side growth trends between digital storefront pipelines (Online) and brick-and-mortar storefronts (Offline).

## 🚀 Key Visual Capabilities

* **Data-Point Annotations:** Automatically calculates value placement heights to print absolute values directly on top of graphical items.
* **Structural Chart Adjustments:** Incorporates multi-color legends, layout grids, and structural adaptations (horizontal/vertical transformations).
* **Multi-Channel Categorization:** Groups metrics side-by-side to allow instant analytical comparisons between separate commercial flows.

1. Confirm that Python is configured in your system workspace path.

   ```bash
   pip install matplotlib pandas
   ```
3. Clone or download this unified repository workspace onto your computer.
4. Open your terminal window or command prompt directly inside the project directory.
5. Launch your desired analytical visualization routine by executing its specific index script. For example, to generate the multichannel sales channel chart:
